    Calculus I cheat sheet

    Limits

    For a polynomial, substitute the value x approaches. If substitution gives 0/0, factor first, cancel the shared factor for x values nearby, then evaluate the simplified expression.

    Derivatives

    Power rule: d(xⁿ)/dx = nxⁿ⁻¹. Differentiate sums term by term; constants become 0. For a function inside another function, use the chain rule: differentiate the outside, keep the inside, then multiply by the inside’s derivative.

    Optimization

    Identify the quantity to maximize or minimize. Find critical points by solving f′(x) = 0, then use the context or the second derivative to decide which gives the desired extreme.

    Antiderivatives

    Reverse the power rule: increase the exponent by 1, divide by the new exponent, and add + C. For x⁻¹, use ln|x| + C.

    Definite integrals

    Find an antiderivative F, then evaluate F(b) − F(a). The result is signed accumulation: reversing the bounds reverses the sign.

    Quick process: name the topic → write the matching rule → apply it carefully → check signs, bounds, and constants.
